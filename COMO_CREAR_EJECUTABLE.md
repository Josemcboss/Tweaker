# 🎁 CÓMO CREAR EJECUTABLE PARA COMPARTIR

## ⚡ MÉTODO RÁPIDO (1 click)

### Ejecuta este archivo:
```
BUILD_AND_ZIP.bat
```

✅ Esto creará automáticamente:
- Ejecutable optimizado
- Archivo ZIP listo para compartir
- Ubicación: `publish\GhostOptimizer_v2.5.0_Windows_x64.zip`

---

## 📋 PASOS:

1. **Doble click** en `BUILD_AND_ZIP.bat`
2. Espera a que compile (1-2 minutos)
3. Encuentra el ZIP en: `publish\GhostOptimizer_v2.5.0_Windows_x64.zip`
4. **¡Listo para compartir!** 🎉

---

## 📤 COMPARTIR:

### Opciones rápidas:
- **Google Drive** / OneDrive / Dropbox → Sube y comparte enlace
- **WeTransfer** → https://wetransfer.com (sin cuenta)
- **Discord/Telegram** → Arrastra el ZIP al chat
- **GitHub Release** → Crea release y adjunta el ZIP
