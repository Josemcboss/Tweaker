# Core Hardware Infrastructure Implementation Plan

## Overview
Refactor the synchronous and limited `HardwareDetector` utility into a robust, asynchronous service architecture. This involves creating a detailed `HardwareInfo` model and a singleton `HardwareScanner` service using WMI.

## Scope Definition (CRITICAL)
### In Scope
- Create `Models/HardwareInfo.cs`.
- Create `Services/AntiCheatScanner.cs` (extracted from `HardwareDetector.cs`).
- Create `Services/HardwareScanner.cs` (Singleton with `ScanAsync`).
- Update `App.xaml.cs` and `MainWindowViewModel.cs` to use the new service.
- Delete `Utilities/HardwareDetector.cs`.

### Out of Scope (DO NOT TOUCH)
- Modifying `HardwareMonitorService.cs`.
- Changing tweak logic based on hardware (this is for future tickets).
- Modifying UI components (unless necessary for model compatibility).

## Current State Analysis
- `Tweaker\Utilities\HardwareDetector.cs`: Contains `HardwareInfo` (L10-L24), `HardwareDetector` (L26-L165), and `AntiCheatDetector` (L167-L215).
- `MainWindowViewModel.cs` (L245): Synchronously calls `HardwareDetector.Detect()`.
- `App.xaml.cs` (L45): Calls `HardwareDetector.Detect()` in `Task.Run`.

## Implementation Phases

### Phase 1: Models & Modularization
- **Goal**: Establish the data structure and separate concerns.
- **Steps**:
  1. [x] Create `Tweaker\Models\HardwareInfo.cs` with the following fields:
     - CPU: Name, Vendor, Cores, Threads, ClockSpeed, IsRyzen, IsIntel.
     - GPU: Name, Vendor, VRAM, IsNvidia, IsAMD.
     - RAM: TotalGB, SticksCount.
     - Storage: Type (SSD/HDD), CapacityGB, IsSSD.
     - OS: Version, Build, IsWindows11.
     - Misc: List<string> DetectedAntiCheats.
  2. [x] Create `Tweaker\Services\AntiCheatScanner.cs` by migrating the `AntiCheatDetector` logic from `HardwareDetector.cs`.
