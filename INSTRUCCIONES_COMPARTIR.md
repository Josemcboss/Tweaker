## ❓ SOLUCIÓN DE PROBLEMAS

### Error: "dotnet no se reconoce como comando"
**Solución:** Instala .NET 10 SDK
https://dotnet.microsoft.com/download/dotnet/10.0

### Error: "No se encuentra Tweaker.csproj"
**Solución:** Ejecuta BUILD_AND_ZIP.bat desde la raíz del proyecto

### El script se cierra inmediatamente
**Solución:** Ejecuta el .bat desde CMD o PowerShell para ver errores

### El ZIP no se crea
**Solución:** Ejecuta como Administrador

## 🔐 VERIFICACIÓN DE INTEGRIDAD (Opcional)

Si quieres verificar que el archivo no se corrompió en la descarga:
