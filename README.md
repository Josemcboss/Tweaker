## ?? Instalación

### **Método Rápido**

1. **Descargar** `Tweaker.exe`
2. **Click derecho** ? **Ejecutar como Administrador**
3. **Aceptar** UAC prompt
4. ¡Listo! La aplicación se abre automáticamente

### **Primera Ejecución**

1. La aplicación te pedirá crear un **Punto de Restauración**
   ```
   ?? RECOMENDADO: Crear punto de restauración antes de continuar
   ```
   - Click en **"Sí"** para crear uno automáticamente
   - Click en **"No"** si ya tienes uno reciente

2. El **Dashboard** se abre mostrando:
   ```
   ??????????????????????????????????????????????????????????????
   ?  0 / 58 Tweaks Activos        0% optimizado               ?
   ??????????????????????????????????????????????????????????????
   ```

3. Navega por las **categorías** en el menú lateral:
   - ?? Dashboard
   - ?? Input & Visuals
   - ?? Red & Ping
   - ?? Sistema & GPU
   - ?? Limpieza
   - ?? GHOST Pack
   - ?? Advanced

4. **Activa tweaks** con el botón **ON (verde)**
5. **Desactiva tweaks** con el botón **OFF (rojo)**
6. **Reinicia Windows** si se requiere

## ??? Sistema de Seguridad

### **ServiceGuard**
Protege servicios críticos de ser deshabilitados accidentalmente:

```csharp
protected_services = [
    "wuauserv",    // Windows Update (backup)
    "EventLog",    // Event Log (diagnóstico)
    "DcomLaunch",  // DCOM (sistema)
    "RpcSs",       // RPC (comunicación)
    "LanmanServer" // File Sharing
]
```

### **OptimizationBackup**
Backup automático antes de cada cambio:

```
%LOCALAPPDATA%\GhostOptimizer\Backups\
?? backup_registry_20250125_153045.reg
?? backup_services_20250125_153112.json
?? backup_bcdedit_20250125_153145.txt
```

### **Script de Rescate**
Generado automáticamente en:
```
%LOCALAPPDATA%\GhostOptimizer\Rescue\
?? RESCUE_SCRIPT_20250125_153045.ps1
```

Ejecutar en PowerShell (Admin) para revertir todo:
```powershell
powershell -ExecutionPolicy Bypass -File RESCUE_SCRIPT_20250125_153045.ps1
```

## ?? Revertir Cambios

### **Método 1: Botones OFF (Recomendado)**
1. Ir a la categoría del tweak
2. Click en **OFF (rojo)**
3. Reiniciar si es necesario

### **Método 2: Revertir Todos (Nuclear)**
1. Ir al **Dashboard**
2. Click en **"REVERTIR TODOS LOS TWEAKS"**
3. Confirmar acción
4. Reiniciar Windows

### **Método 3: Script de Rescate**
1. Ir a `%LOCALAPPDATA%\GhostOptimizer\Rescue\`
2. Click derecho en `RESCUE_SCRIPT_*.ps1`
3. **Ejecutar con PowerShell (Admin)**
4. Reiniciar Windows

### **Método 4: Punto de Restauración**
1. Abrir **Restauración del Sistema**
2. Elegir punto creado antes de usar Ghost Optimizer
3. Seguir wizard de restauración
4. Reiniciar Windows

## ?? Soporte

### **Problemas Comunes**

#### ? **"El sistema está lento después de aplicar tweaks"**
**Solución:**
1. Ir a **Network** ? **Optimización Balanceada**
2. Aplica perfil balanceado para navegadores
3. Desactiva **Spectre/Meltdown** si lo activaste
4. Reinicia Windows

#### ? **"Los navegadores no cargan páginas"**
**Solución:**
1. Ir a **Network** ? **DNS**
2. Aplicar DNS Cloudflare o Google
3. Ir a **Cleanup** ? **Flush DNS**
4. Reiniciar navegador

#### ? **"Juego crashea al iniciar"**
**Solución:**
1. Desactivar **Spectre/Meltdown** (Advanced)
2. Activar **Core Isolation** si lo desactivaste
3. Desactivar **HPET** tweak
4. Reiniciar Windows

#### ? **"No puedo imprimir"**
**Solución:**
1. Ir a **Cleanup** ? **Ultimate Debloat**
2. Click en **RESTAURAR** (Services Optimization)
3. Reiniciar Windows
4. El servicio Spooler se reactivará

## ?? Build desde Código Fuente

### **Requisitos**
- Visual Studio 2022 (o superior)
- .NET 10 SDK
- Windows 10/11 SDK

### **Compilar**
```bash
# Clonar repositorio
git clone https://github.com/Josemcboss/Tweaker.git
cd Tweaker

# Restaurar paquetes
dotnet restore

# Build Release
dotnet build --configuration Release

# Publicar (single-file)
dotnet publish --configuration Release --runtime win-x64 --self-contained true /p:PublishSingleFile=true
```

O simplemente ejecutar:
```bash
Build.bat
```
