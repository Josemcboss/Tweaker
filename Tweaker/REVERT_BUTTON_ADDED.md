## ?? Casos de Uso

### Cuándo usar este botón:
1. **Testing:** Probar el sistema sin tweaks
2. **Problemas:** Algo salió mal con los tweaks
3. **Venta del PC:** Restaurar a stock antes de vender
4. **Cambio de hardware:** GPU/CPU nuevo puede necesitar diferentes tweaks
5. **Emergencia:** Botón de pánico si el sistema no funciona bien
